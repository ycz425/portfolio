01 Featured Project

AutoML Agent

Describe an ML task in plain English. A team of LLM agents plans it, runs it, and ships you a trained model.

Live Demo View Source

AutoML Agent is a full-stack, multi-agent system that automates the machine learning workflow end to end. A user uploads a dataset and states a goal in natural language; a graph of specialized LLM agents clarifies the request, analyzes the data, drafts an experiment plan, generates and repairs model code, and reports results back — with no manual feature engineering or model selection required.

Multi-agent orchestration

A LangGraph state machine coordinates six specialized agents — clarification, data analysis, planning, prompting, experimentation, and output — each with a narrow responsibility and a typed handoff to the next.

Self-repairing experiments

Generated training code is library-agnostic — the agent picks whatever Python ML libraries fit the task, installs them in an isolated environment, and automatically repairs failures instead of dead-ending.

Production ML lifecycle

Beyond training: served predictions, drift monitoring on live predictions via Evidently, and a one-click retrain flow when performance degrades.

Evals & observability

Every agent has a LangSmith eval suite wired into CI, plus full tracing — so regressions in agent behavior get caught before they ship.

Deployed on GCP

The backend runs on Cloud Run, with Cloud Storage and Firestore handling persistence, and the frontend served through Firebase Hosting.
